# prefabs/plants/

植物预制体。文件名必须与 `PrefabPath` 对应常量末尾段一致。

| 常量 | 文件 |
|---|---|
| `PrefabPath.SUNFLOWER` | `Sunflower.prefab` |
| `PrefabPath.PEASHOOTER` | `Peashooter.prefab` |
| `PrefabPath.WALLNUT` | `Wallnut.prefab` |
| `PrefabPath.CHERRY_BOMB` | `CherryBomb.prefab` |
| `PrefabPath.SNOW_PEA` | `SnowPea.prefab` |
| `PrefabPath.REPEATER` | `Repeater.prefab` |

镜像目录：`assets/resources/prefabs/plants/`
